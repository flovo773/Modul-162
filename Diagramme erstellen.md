# Kurzfassung: Diagramme in Excel erstellen

So gehst du sicher vor:

In Excel die Stelle anklicken, an der das Diagramm erscheinen soll.
Über Einfügen / Insert ein Diagramm einfügen, ohne vorher Daten zu markieren.
Rechtsklick auf das leere Diagramm → Daten auswählen / Select Data.
Mit Hinzufügen / Add eine Datenreihe hinzufügen.
Den Namen der Datenreihe auswählen, z. B. „SP“.
Danach die zugehörigen Werte markieren.
Anschliessend die Kategorien / Achsenbeschriftungen auswählen, z. B. die Jahre.
Für weitere Datenreihen den gleichen Vorgang wiederholen. Die Kategorien müssen nur einmal festgelegt werden.
Diagramm beschriften

Unter Chart Design → Add Chart Element kannst du hinzufügen:

## Diagrammtitel
Achsentitel
Legende
weitere Diagrammelemente
Wichtig

Bei einer Datenreihe kann Excel den Namen der Reihe automatisch als Titel verwenden. Bei mehreren Datenreihen werden die Namen normalerweise in der Legende angezeigt.

Bei manchen Diagrammtypen gelten besondere Regeln. Ein Kreisdiagramm kann beispielsweise nur eine Datenreihe sinnvoll darstellen.

## Merksatz:
Diagramm einfügen → Daten auswählen → Serie bestimmen → Werte bestimmen → Kategorien bestimmen → Titel und Legende ergänzen.
