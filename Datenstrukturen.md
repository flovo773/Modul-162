Kurzfassung: Datenstrukturen

Datensatz / Record / Tupel

fasst mehrere zusammengehörende Werte zusammen
Beispiel: ID, Vorname, Nachname, Telefonnummer
entspricht ungefähr einer Zeile in einer Tabelle

Array

speichert mehrere Werte, meist vom gleichen Datentyp
Zugriff erfolgt über einen Index
kann ein- oder mehrdimensional sein
Beispiel: [12, 45, 23, 38]

Verkettete Liste

speichert beliebig viele Elemente
jedes Element verweist auf das nächste Element
gut zum Einfügen und Löschen von Elementen

Stack / Stapelspeicher

funktioniert nach LIFO
Last In – First Out
push = hinzufügen
pop = letztes Element entfernen

Queue / Warteschlange

funktioniert nach FIFO
First In – First Out
enqueue = hinzufügen
dequeue = erstes Element entfernen

Priority Queue

Elemente werden nach Priorität eingeordnet
das Element mit der höchsten Priorität kommt zuerst

Graph

Elemente können mit mehreren anderen Elementen verbunden sein
Beispiel: GPS-Navigationssystem

Baum

spezielle Form eines Graphen
besitzt hierarchische Verbindungen
Suchbäume ermöglichen schnelles Finden von Elementen

Heap

verbindet einen Baum mit einer Prioritätswarteschlange
wichtige Operationen: insert, remove, extractMin

Hashtabelle

Speicherposition wird über einen Schlüssel direkt berechnet
dadurch können Daten sehr schnell gefunden werden

Merksatz:
Stack = LIFO, Queue = FIFO, Priority Queue = höchste Priorität zuerst, Array = Zugriff über Index.
